 How to play?
1. Download .html file
2. go to your file manager
3. Search for .html which was downloaded earlier
4. Click the file logo
5. Click open with, then select Chrome or other browser

  How to play on app?
 1. Download .apk file
 2. Go to your file manager
 3. Search for .apk file which was downloaded earlier
 4. Click file logo
 5. Click open with, then select application installer or .apk installer, then click download but if a Google Play warning pop up appears, click scan application or click the down arrow and click download anyway
