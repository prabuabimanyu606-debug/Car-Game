How to play on app?

1. Download .html file
2. Donwload html to apk converter
3. Follow app instruction to make .html file into .apk file
4. Download .apk file
5. Go to your file manager
6. Search for .apk file which was downloaded earlier
7. Click file logo
8. Click open with, then select application installer or .apk installer, then click download but if a Google Play warning pop up appears, click scan application or click the down arrow and click download anyway
